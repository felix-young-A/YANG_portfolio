## 执行检查点（Pre-Delivery Checklist）

在生成最终文档之前，**必须自查**以下问题并在内部记录答案：

- [ ] 是否已尽最大努力获取完整内容？
- [ ] 是否已尝试获取字幕？（结果：有完整字幕 / 仅有部分字幕 / 无字幕）
- [ ] 字幕是否完整覆盖？（是 / 否）
- [ ] 是否已尝试音频转写？（是 / 否 / 因 XX 原因跳过 — 说明具体原因）
- [ ] 如用户要求完整文稿，是否已执行音频转写？
- [ ] 网页文章是否已去除所有噪声（广告、推荐、导航）？
- [ ] 内容来源在文档中是否已正确标注？（是 / 否）
- [ ] 降级场景（未获取完整音视频/字幕）是否已在显眼位置标注来源限制与降级依据？（是 / 否 / 不适用）。是否先拉起询问用户意见后再进行其他处理？用户是否答复指示？

若任何一项未满足，**不得进入生成阶段**，应继续补充内容获取。

## 质量检查（Quality Assurance）

交付前**必须逐项检查**：

### 内容完整性
- [ ] 是否选对 A/B/C 类型
- [ ] 是否说明内容依据（字幕/转写/页面/用户提供）
- [ ] 是否按"音频转写判定规则"检查转写需求并执行或合理跳过
- [ ] 是否在"执行检查点"中记录字幕/转写/内容来源自查结果

### 文件交付
- [ ] 文件名是否来自标题并转为英文安全文件名
- [ ] 是否保存到用户可访问的工作区
- [ ] 是否同时生成 Markdown 单文件和 ZIP 完整包
- [ ] 如果包含图片，ZIP 中是否包含 `assets/` 目录且相对路径可用
- [ ] 是否已清除系统自动添加的 AIGC front matter（`---\nAIGC: ... ---` 水印块）与文件末尾"由 AI 生成，仅供参考"等水印提示语

### 格式规范
- [ ] 顶级标题是否为英文（`## Abstract` / `## Key Points` 等）
- [ ] 正文是否为简体中文
- [ ] frontmatter 是否包含全部必填字段（`title` / `host` / `guest` / `source` / `platform` / `date` / `created` / `tags`，无资料字段可留空但不缺失）
- [ ] frontmatter 字段是否为纯文本（无 `[[wikilink]]`）
- [ ] frontmatter 信息是否没有在正文重复
- [ ] 标签是否恰好 2 个（`fieldnote` + 内容类型）
- [ ] base link 是否在 frontmatter 后第一行

### 排版质量
- [ ] 折叠摘要是否使用 Obsidian Callout 语法（`> [!note]-`），没有使用 `<details>` 标签
- [ ] 段落是否控制在 2~4 句话，子主题是否合理拆分（每个章节 3~9 个子主题）
- [ ] 章节之间是否有 `---` 分隔线
- [ ] 是否有明显繁体残留、转写错字、同音误识别（按"转写后处理"纠错表检查）

### A 类排版红线（新增，交付前强制检查）
- [ ] 主标题是否为判断句（一句话核心观点），而非原视频标题直接沿用
- [ ] 章节是否使用 `01 / 02 / 03 …` 编号 + 判断式小标题（正文内无 `1. 2. 3.` 流水编号列表）
- [ ] 是否以独立"结语"段收束（回扣主题、留白收尾）
- [ ] 金句是否独立成段/加粗/引用，且控制在 3~6 处，无"金句："标签前缀
- [ ] 是否有"一大段到底、无重点突出"的段落（有则必须拆分）
- [ ] 全文无 Obsidian Callout 滥用（`[!note]` / `[!quote]` / `[!tip]` / `[!warning]` 等按**语境与场景**使用、不设死板数量上限，但默认普通 `>` 引用为主，日常笔记通常仅折叠摘要 1 个 Callout，避免满屏符号块），无 `<details>` 标签
- [ ] 对谈/访谈类内容是否正确标注说话人、保留对话流动感、观点归属无误（见对谈处理协议）
- [ ] 是否避免"总结板块/分析板块"分离，采用融合式结构（现象呈现 + 逻辑揭示同步）
- [ ] 去 AI 味自检：无套话、无"不是X而是Y"滥用、无"值得注意/深刻/范式"等词、结尾不宣告结束

### 内容质量
- [ ] A 类是否真正提炼成可复用知识，而不是泛泛总结
- [ ] B 类是否保留原生文稿而不是改写
- [ ] C 类是否去除广告和网页噪音

### iframe 校验
- [ ] iframe 是否指向当前主视频（非推荐/相关视频）
- [ ] 至少比对了标题、作者、时长、日期中的两项
- [ ] 找不到可验证主视频时是否写了"待确认"而非放错 iframe

## 回复用户（Response Template）

完成后简洁说明处理类型、依据和文件链接。

**A 类示例**：

```markdown
已按视频知识笔记模式整理完成，基于音频转写提炼为可复用知识文档，并保留英文模块标题。

[查看 Markdown](computer:///workspace/example-title.md)

[下载完整 ZIP 包](computer:///workspace/example-title-package.zip)
```

**B 类示例**：

```markdown
已按视频原生文稿模式整理完成，基于音频转写生成逐字稿，已修正错字和排版。

[查看 Markdown](computer:///workspace/example-title.md)

[下载完整 ZIP 包](computer:///workspace/example-title-package.zip)
```

**C 类示例**：

```markdown
已按网页文章清理模式整理完成，已去除广告和无关内容，保留正文结构。

[查看 Markdown](computer:///workspace/example-title.md)
```
