## A 类写作标准

### ① 处理流程（五步走）

1. **通读提主线**：完整理解原稿，用一句话写出全文核心论点；若原稿有多个主题，拆分为若干篇，每篇只讲一个主线
2. **识块定框架**：按"案例/现象 → 机制 → 方法/判断 → 边界/坑点"的逻辑脉络，把内容组织为 3-6 个递进章节，最后以"结语"或"行动清单"收束
3. **章节贴论点**：为每章写一个判断式小标题（本章核心观点，而非内容概述），让读者只看标题就能串起全文
4. **填充与金句化**：章节内先放核心判断，再用原视频案例/论据支撑；把可复用的结论提炼成可独立引用的短句
5. **节奏打磨**：长段落讲理、短句收束；删套话、去 AI 味；检查章节过渡；结语回扣主题、留白收尾

### ② 写作协议

- **信息守恒**：核心观点、关键案例、重要数据必须保留，不因整理而丢失；允许合并重复、删除口语噪音；**对照原稿逐项核对**：补充说明、警示/提示块、引用块、对比细节、数据出处不得因排版或"精简"整体删除，宁可保留原细节，也不要压缩成概括句
- **事实边界**：严禁新增原稿未出现的事实、数据、案例或立场；不确定信息标注"原稿未详述"
- **观点归属**：这是"整理"而非"评论"——分析视角可以补强，但不得歪曲原作者立场
- **具体优先**：先把视频里的具体案例讲清楚，再抽象方法论；把"发生了什么"整理成"以后可怎么判断/怎么做"
- 不要只写泛泛观点，例如"要先跑通流程"；要写清流程是什么、为什么、怎么验证、失败信号是什么
- 适合知识库的内容包括：原则、步骤、判断标准、反例、风险、适用范围、操作提示
- 如果视频里只有经验分享，也要提炼成稳定概念，而不是流水账

### ③ 精校处理协议（六条，借鉴原文案提示词，必须逐条执行）

1. **去芜存菁**：删除口头禅（"这个那个""就是说"）、无效重复、犹豫停顿、修正自己的无效表述；将颠倒残缺的句子重组为符合中文语法、完整流畅的句子
2. **隐喻守护**：完整保留说话者的比喻和隐喻；隐喻因口语表达而显得跳跃晦涩时，用括号（）附一句简短解释，但绝不替换或删除隐喻本身
3. **哲学解码**：保留核心术语名词；过于抽象或冗长的论述用更精炼清晰的语言重述其核心逻辑，必要时用括号（）补一个通俗比喻或解释，不牺牲深度地提升可读性
4. **幽默规整**：以巧妙得体的方式处理"荤段子"或不雅笑话——改写为更含蓄、更具文学性的表达，保留幽默本质、去除直白粗俗词汇，让读者心领神会
5. **客观原生视角**：理性克制的分析语感，避免情绪化宣泄；**保持原视频的陈述视角**，不添加"拆解""核查""回到信源"等评论引导词，需要交代信源或做对照时直接陈述事实；高效冷静且不失风趣的高信息密度输出
6. **结构重塑**：为流畅的口语赋予清晰的、适合博客阅读的书面结构；根据内容逻辑脉络自然切分段落，主题转换处使用判断式小标题
- **三轮迭代**：第一轮专注结构和逻辑流畅（应用结构重塑，补充过渡、切分段落）；第二轮专注语言风格和叙事性（应用去芜存菁、隐喻守护、哲学解码、幽默规整、客观原生视角口吻，炼金句）；第三轮专注约束检查与细节统一（信息守恒逐项核对、统一术语）
- **输出即成品**：直接输出最终精校文本，不包含任何处理过程的解释或元语言

### ④ 金句提炼标准

- 一句话能说清的观点，不要用两句话；金句要**可截图**——独立成段后不依赖上下文也能被理解
- 优先提炼：核心判断、反常识观点、比喻句、对仗句
- 每篇整理稿的金句控制在 3-6 处，避免满篇都是重点（满篇重点 = 没有重点）

### ⑤ 去 AI 味规则（完整版，借鉴原文案提示词，产出必须逐条自检）

**【用词根据场景合适度，尽量避免以下类词汇】**
- "深刻/深入/根本性/显然/值得注意"等假装有分量的副词
- "探讨/深挖/剖析/梳理/解读"等 AI 口头禅动词
- "图景/生态/范式/框架/协同"等大词空词
- "作为……而存在/充当……角色"等用来代替"是"的绕弯说法
- "固然……但……""尽管面临挑战……"等公式化转折
- 凡是要加"值得一提的是""重要的是""有趣的是"才能引出的内容，要么砍掉，要么直接说

**【句式尽量避免使用的例子】**
- 禁用"不是X，而是Y"结构（偶尔一次可以，全篇超过两次就是 AI 告示牌）
- 禁用"不是X，不是Y，而是Z"倒计时煽情句
- 不适合的文章语境场景不要自问自答："结果如何？灾难性的。"
- 禁用连续三句以上相同句式开头的排比
- "让我们来……""我们不妨……""接下来我们将……"等老师腔
- "想象一个世界……"式的宏大开场
- 禁用"综上所述""总结而言""最后"等标注结构的收尾词

**【格式：在不适合的场景 尽量要避免的格式】**
- 禁用每个 bullet 点都加粗首词的列表格式
- 禁用"第一……第二……第三……"伪装成散文的列表（本 skill 的 `01/02/03` 是章节级判断式小标题，不是正文里的流水编号；正文内禁止用 1. 2. 3. 把论述拆成死板条目）
- 全篇 em 破折号不超过 3 处
- 禁止首尾互相呼应的"我在开头说了X，现在我们回到X"式的闭环结构
- 禁止每个段落末尾加一句强行点题（如"凸显了……的重要性""体现了……的价值"）

**【思维禁区】**
- 不要把每个论点都夸张成"定义了一个时代"的大事
- 不要用"专家认为""研究表明"而不给出具体来源
- 不要发明"X悖论""Y陷阱""Z效应"等听起来像术语的自造概念
- 不要用一个比喻贯穿全文反复用烂
- 不要把一个观点换十种说法重复陈述，凑字数

**【真正要做的】**
- 用短句点题，用长句展开，长短交替，不要一刀切
- 直接说"是"，不要说"作为……而存在"
- 具体胜于抽象：用一个真实细节代替三个形容词
- 结尾不需要宣告"我要结束了"，写完就停
- 承认不确定的事情时说"我不知道"，不要表演成"这是一个值得深思的复杂议题"
- 口语检验：逐段读，你会这样跟朋友说吗？不会 → 改。压缩后再过一遍口语——嘴说不出来了就回退
- 重点靠结构表现，不靠元语言点破——禁止"这背后关乎一个更根本的问题""这里需要澄清一个误解""于是形成一个危险的闭环"等导语式套话；逻辑关系通过段落组织自然呈现

### ⑥ 排版执行红线（模板强制，优先级最高，产出时必须逐项落地）

- **主标题必须重写为判断句**（如"捂嘴是特权，特权不能乱弄"），禁止直接沿用原视频标题作主标题；原视频标题只保留在 frontmatter 的 `title` 字段或副题中
- **章节必须用 `01 / 02 / 03 …` 编号 + 判断式小标题**（小标题是本章核心观点，不是内容概述），最后以独立"结语"段收束
- **金句必须独立成段**并加粗或放入引用块，作为"可截图传播"的视觉锚点；每篇 3~6 处，避免满篇重点；直接以短句本身呈现，**禁止添加"金句："等标签前缀**
- **段落控制**：每段 2~4 句，超过 5 行必须拆分；长短句交替（长句讲理、短句收束），禁止一段到底
- **章节之间用 `---` 分隔线隔开**，形成视觉节奏；结语回扣开篇、留白收尾

### ⑦ 融合式结构（借鉴原文案"老梅视频总结"，对访谈/叙事类内容尤其重要）

- **禁止"总结板块/分析板块"分离**：不要在笔记里先堆一段"内容总结"，再来一段"我的分析"。全文必须在同一结构中完成"现象呈现 + 逻辑揭示"的同步推进
- **锚定（Summary）+ 揭示（Analysis）同步**：先精炼概括原文的具体策略、困境或现象，紧接着解释其背后的来源、深层目的、手段有效性或潜在代价；允许在段落内自然嵌入总结句，让读者在阅读过程中同时完成"发生了什么"与"为什么/如何起作用"
- 操作示例：描述"展品轮换"这一事实时，同段阐述其背后的"存量盘活逻辑"，而不是先写事实、隔几段再写分析
- 分析视角可以补强，但不得歪曲原作者立场（与"观点归属"一致）

### ⑧ 得意忘言与表达效率（借鉴原文案提示词 8）

- 提炼的宗旨是**得意忘言**：不必追求对原文本的完整概括和保留，而要在原文基础上找到最合适的修辞进行最效率的表达
- 与"信息守恒"的关系：核心观点、关键案例、重要数据必须守恒（不删不丢），但**表达层追求效率**——删除套话、废话、重复表述，不为"显得完整"而保留无信息量的句子
- 如果一个观点可以用一个精妙的比喻说清，不要用三句平庸的陈述
- 四条写作原则（选一条贯穿全文，让文章"活"起来）：
  1. **一个锚点撑全文**：找到一个具象的中心隐喻（一张图、一个场景、一个动作），让所有概念围绕它生长；不是并列罗列五个概念，是一根绳子串起来
  2. **推理外显**：模拟"一个人想明白的过程"，而非呈现"想明白之后的结果"；用"既然A是B，那能不能C也是D？"带读者一起推，让读者觉得结论差一步就是自己想到的
  3. **变形替代定义**：解释两个概念的关系时，把 A 连续变形成 B，不要说"A和B是XX关系"
  4. **落点在能用**：给出"这意味着你可以___"，而非"这让我们重新思考___"；读者读完要带走一个能动手的东西，不是一个值得沉思的感慨
- **顶部一句话核心**：在开头用一句话说清楚核心观点（学术基础上稍微偏向大众化），再展开；不写免责声明，不夸奖，不编造引用

### ⑨ 对谈/访谈类内容处理协议（多说话人场景强制）

- **说话人标注**：用普通加粗姓名 + 冒号（如 `**周小辣**：`），段落内自然呈现；**禁止**使用"声纹基频""说话人A/B"等过度工程化标注；对话中的精彩原话如需突出，可用普通 `>` 引用或正文加粗，金句级原话也可用 `[!quote]`（克制，不用在普通问答流水）
- **分清对话双方**：必须正确归属观点——谁说的归谁，不能张冠李戴；转写稿中无法可靠区分说话人时，按内容逻辑推断，不确定的标注"（说话人待确认）"
- **保留对话的流动感**：问答、交锋、打断、补充、情绪是对话的价值所在，不要机械地拆成"观点1、观点2、观点3"的列表；保留一来一回的节奏，让读者感受到是两个人（或多人）在对话
- **提炼核心交锋**：章节按对话中的核心议题/交锋组织，而不是按发言顺序流水账；每个章节围绕一个议题，把双方（多方）围绕该议题的做好后续验证
